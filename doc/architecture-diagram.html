🔄 Auth Flow Firebase → Backend → Supabase
Mobile / Web
user signs in
→
Firebase Auth
returns ID token
→
Backend API
verifies token
→
Supabase DB
queries with firebase_uid
→
Client
receives data

Key design decision: Firebase handles authentication only. The backend verifies the Firebase ID token on every request using the Firebase Admin SDK. Supabase stores all application data — user rows reference the firebase_uid field instead of Supabase's native auth UUID.
